# 验证记录

截至 2026 年 10 月 16 日，项目内复制方案已完成以下验证：

- 18 个 Python 测试通过，覆盖任务格式、依赖调度、限量执行、状态查询、失败与中断恢复、定义变更、`blocked` 任务在下一次运行时优先重试且每轮只试一次，以及从本仓库复制工具包到无关项目后的完整执行。
- 跨项目测试使用 `python -S` 禁用第三方包，证明 JSON 计划只需 Python 标准库。该测试在独立临时项目中执行两个有依赖的任务，第一轮只运行一个任务，第二轮续跑并确认状态全为 `done`；重新安装工具包不会覆盖项目配置或 README。
- YAML 路径由已有 PyYAML 测试覆盖；源 skill 和项目内 skill 均通过 skill-creator 格式校验。

测试用替身 Codex CLI 校验了运行器与外部进程的接口。真实 Codex 云端执行受当前沙箱网络限制：进程环境标记 `CODEX_SANDBOX_NETWORK_DISABLED=1`，直接运行 `codex exec` 时客户端初始化失败，改用临时 `CODEX_HOME` 后请求 Codex 服务仍发生 DNS 失败。因此真实模型完成任务的冒烟验证未在此环境通过；在可访问 Codex 服务的环境中可运行 `python3 scripts/smoke_real_codex.py` 复验。此项限制不影响复制集成和本地流程测试，也不需要增设本地 API。
